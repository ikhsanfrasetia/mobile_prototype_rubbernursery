## 5. Tata Kelola & Aturan Status Dokumen

1. **Status Awal:** Dokumen berada pada status `FINAL / FOR REVIEW` dengan keputusan `PENDING`.
2. **Kondisi Approved:** Jika seluruh stakeholder menyetujui, status dinaikkan menjadi `FINAL / APPROVED`.
3. **Kondisi Approved with Notes:** Jika terdapat catatan, status dinaikkan menjadi `FINAL / APPROVED WITH NOTES` dan seluruh catatan diarsipkan ke *Change Log*.
4. **Kondisi Rejected:** Jika ditolak, baseline tidak diubah otomatis melainkan dicatat ke dalam *Rejection / Issue Register* untuk diselesaikan dalam sesi klarifikasi.
